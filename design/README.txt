Cross-Team: самостоятельная визуальная система.

Метафора: спокойное рабочее бюро, где людская экспертиза становится общим ресурсом.
Палитра: бумага #f6f4ee, карточки #fffefa, тёмный хвойный #202b29, медь #a34d32.
Типографика: локальный системный стек Segoe UI / Arial; крупные заголовки, табличные числа.
Навигация: постоянный rail на desktop, выдвижная панель на mobile.
Компоненты: лаконичные SVG-иконки, таблицы, профили с инициалами, полосы загрузки,
статусы с текстом, доступны с клавиатуры; модальные формы с ошибками сервера.
Сторонние CDN, изображения, шрифты и библиотеки UI не используются.
Экраны: вход, обзор, сотрудники/профиль, проекты/позиции, поиск, приглашения,
назначения, отзывы, справочник, аналитика, история событий.
